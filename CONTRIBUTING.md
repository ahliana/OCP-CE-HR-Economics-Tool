# Contributing to OCP Heat Reuse Economics Tool

Thank you for your interest in contributing to this project. This tool is being developed for the Open Compute Project, and all contributions are welcome.

## How to Contribute

### Reporting Issues

If you find a bug, have a question, or want to suggest an improvement:

1. Go to [GitHub Issues](https://github.com/opencomputeproject/OCP-CE-HR-Economics-Tool/issues)
2. Click "New Issue"
3. Provide a clear description including:
   - What you expected to happen
   - What actually happened
   - Steps to reproduce the problem
   - Your operating system and Python version
   - Any error messages (full text)

### Suggesting Features

Feature suggestions are welcome. When proposing new features:

1. Check existing issues to avoid duplicates
2. Describe the use case - why is this feature needed?
3. Explain how it would work from a user's perspective
4. If possible, suggest how it might be implemented

### Submitting Code Changes

To contribute code:

1. **Fork the repository** on GitHub

2. **Create a feature branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes:**
   - Follow existing code style
   - Add comments for complex logic
   - Test your changes locally

4. **Commit with clear messages:**
   ```bash
   git commit -m "Add feature: brief description"
   ```

5. **Push to your fork:**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Create a Pull Request:**
   - Go to the original repository
   - Click "Pull Requests" > "New Pull Request"
   - Select your fork and branch
   - Describe your changes

## Review Process

All contributions are reviewed by Ahliana Byrd before being merged. This ensures:

- Code quality and consistency
- Alignment with project goals
- Compatibility with OCP requirements

Please be patient during review. You may receive feedback requesting changes before your contribution is accepted.

## Code Guidelines

- **Python version:** Target Python 3.9+
- **Style:** Follow PEP 8 guidelines
- **Dependencies:** Minimize new dependencies; discuss before adding
- **Documentation:** Update relevant docs when changing functionality
- **Testing:** Verify changes work locally before submitting

## Types of Contributions Needed

- Bug fixes
- Documentation improvements
- Additional unit conversions
- UI/UX improvements
- Performance optimizations
- New calculation methods (with engineering justification)
- Translations

## Questions?

For questions about contributing:

- Open a [GitHub Issue](https://github.com/opencomputeproject/OCP-CE-HR-Economics-Tool/issues) with your question
- Tag it with "question" label
